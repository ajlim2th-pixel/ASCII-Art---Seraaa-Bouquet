ASCII Art - Seraaa 🌷

A single-file love letter for Hannelore. Five pink ASCII tulips slowly open and close beside a bow-sealed envelope. Tap the envelope and a sheet of paper slides out, unfolding into a handwritten-style note with pink rules and kitten illustrations.

![Photo](./photo.png)


Open the letter

Download petal-post.html and open it in a browser. All HTML, CSS, JavaScript, and illustrations are included in the file, so it works offline.

Click or tap the pink envelope to read the letter.

Choose Close or press Escape to return to the bouquet. The envelope stays open.

Choose ✿ Reset bouquet to seal the envelope, return the flowers to buds, and read it again.

Make it yours

Letter text — In petal-post.html, search for EDIT YOUR LETTER HERE to change the greeting, paragraphs, and signature.

Dedication — Search for For my baby, hannelore to change the name above the bouquet.

Bloom timing — Each tulip takes seven seconds to open and seven seconds to close. Change BLOOM_DURATION_MS to adjust the duration of each phase.

Writing lines — The --row CSS property controls both the spacing of the pink rules and the line height of the letter.
